# 📋 ระบบจัดตารางงานพนักงานรายสัปดาห์ (ShiftMate)

เว็บแอปพลิเคชันสำหรับจัดตารางงานพนักงานรายสัปดาห์ (จันทร์–สัปดาห์)
รองรับ **มือถือเป็นหลัก (Mobile-first)** และ **Responsive**

- 🌐 **เวอร์ชันออนไลน์:** https://saharatyokthuan.github.io/shiftmate/
- 💾 **โหมดหลัก:** ทำงานฝั่ง Client 100% เก็บข้อมูลใน `localStorage` (ไม่ต้องมีเซิร์ฟเวอร์)
- 🐍 **โหมดเสริม:** มี Backend API (Flask + SQLite) และเครื่องมือสำรองข้อมูลให้ใช้ได้เช่นกัน (ดูหัวข้อ [Backend API](#-backend-api-ไม่บังคับ))

## 🚀 เริ่มใช้งาน

### วิธีที่ 1: เปิดตรง
ดับเบิลคลิก `index.html` เปิดด้วยเบราว์เซอร์ได้ทันที

### วิธีที่ 2: ผ่าน Local Server (แนะนำ — เลี่ยงปัญหาสิทธิ์การโหลดไฟล์)

```bash
# Python
python -m http.server 8080

# Node.js
npx serve

# หรือใช้สคริปต์ที่ให้มา (เปิดเบราว์เซอร์ + โชว์ URL ให้มือถือในวง LAN เข้าได้)
python server.py
```

แล้วเปิดเบราว์เซอร์ที่ http://localhost:8080

### เริ่มใช้งานครั้งแรก
ระบบจะ seed ผลัด 8 รายการให้อัตโนมัติ (ดูตารางด้านล่าง) จากนั้น:

1. ไปที่เมนู 👤 **พนักงาน** → เพิ่มพนักงาน
2. ไปที่เมนู 📅 **ตารางงาน** → แตะ cell → เลือกผลัด
3. ไปที่เมนู 📊 **สรุป** → ดูสรุป

## 🐍 Backend API (ไม่บังคับ)

ใช้เมื่อต้องการเก็บข้อมูลบนเซิร์ฟเวอร์ (SQLite) แทน localStorage
⚠️ **Frontend ใน repo นี้ไม่ได้เรียก API นี้** — ตัวเว็บเป็น localStorage ล้วน ส่วนนี้เป็น API แยกสำหรับงานที่ต้องการ

### ติดตั้งและรัน

```bash
cd backend
pip install -r requirements.txt      # Flask==3.0.0, flask-cors==4.0.0
python app.py                        # เปิดที่ http://localhost:5000
```

ครั้งแรกจะสร้าง `data.db` (SQLite) และ seed ผลัดเริ่มต้นให้

### Endpoints

| Method | Path | คำอธิบาย |
|---|---|---|
| GET | `/api/employees` | รายชื่อพนักงาน |
| POST | `/api/employees` | เพิ่มพนักงาน |
| PUT | `/api/employees/<id>` | แก้ไขพนักงาน |
| DELETE | `/api/employees/<id>` | ลบพนักงาน |
| GET | `/api/shifts` | รายการผลัด |
| POST | `/api/shifts` | เพิ่มผลัด |
| PUT | `/api/shifts/<id>` | แก้ไขผลัด |
| DELETE | `/api/shifts/<id>` | ลบผลัด |
| GET | `/api/schedule` | ตารางงานทั้งหมด (กรองด้วย `?date=YYYY-MM-DD`) |
| PUT | `/api/schedule/<date>/<emp_id>` | กำหนดผลัดให้พนักงาน (body: `{ shiftId, ot }`) |
| DELETE | `/api/schedule/<date>/<emp_id>` | ลบผลัดของพนักงานในวันนั้น |
| GET | `/api/backup` | ดึงข้อมูลทั้งหมดเป็น JSON |
| POST | `/api/restore` | กู้คืนจาก JSON (แทนที่ข้อมูลเดิมทั้งหมด) |

## 🛠️ เครื่องมือ (tools/)

### `backup.py` — สำรอง/กู้คืนผ่าน API

```bash
cd tools
python backup.py export               # ดึงจาก API → backups/backup_YYYYMMDD_HHMMSS.json
python backup.py import backup.json   # ส่งข้อมูลกลับเข้า API (จะถามยืนยัน)
python backup.py list                 # แสดงไฟล์สำรองทั้งหมด
```

### `convert.py` — แปลง JSON ↔ CSV

```bash
python convert.py backup.json backup.csv   # JSON → CSV
python convert.py backup.csv  backup.json  # CSV → JSON
```

## 📐 กฎทางธุรกิจ

- ✅ 1 พนักงาน = 1 ผลัด/วัน (ไม่เช็คเวลาทับกัน เพราะผลัดทับกันโดยธรรมชาติ)
- ✅ OT เก็บเป็น flag ต่อท้ายผลัด → แสดง chip เดียวเป็น `M +OT`
- ✅ OT checkbox จะโผล่เฉพาะผลัดที่มีการตั้ง `otUntil` ไว้
- ✅ OFF เป็นผลัดปกติ assign ได้ แสดง chip สีเทา
- ✅ ผลัดข้ามวัน ติ๊กได้ในฟอร์มเพิ่ม/แก้ไขผลัด
- ✅ ในสรุป จะไม่นับผลัดที่เป็น OFF เป็น "ทำงาน"

## 💾 การสำรองข้อมูล (ในเบราว์เซอร์)

**Export**

| รูปแบบ | รายละเอียด |
|---|---|
| JSON | เก็บทุกอย่างครบ (employees + shifts + schedule) — แนะนำสำหรับ backup |
| CSV | 1 แถว = 1 พนง. × 1 วัน × 1 ผลัด — เหมาะเปิดใน Excel/Sheets |
| XLSX | 3 sheet: Employees / Shifts / Schedule |

**Import**

- รองรับ `.json` / `.csv` / `.xlsx`
- JSON → แทนที่ข้อมูลทั้งหมด
- CSV → แทนที่ทั้งหมด แล้ว parse กลับเป็น employees/shifts/schedule
- XLSX → อ่าน 3 sheet เหมือนตอน export

> ⚠️ Import จะแทนที่ข้อมูลเดิมทั้งหมด — แนะนำให้ Export เก็บไว้ก่อน

  --c-border: #3d3d5d;   /* สีขอบ */
  --c-danger: #ff6b6b;   /* สีเตือน */

เปลี่ยนสีหลักทั้งแอป → แก้ `--c-primary` ที่เดียว

## 🔒 ความปลอดภัยของข้อมูล

- ข้อมูลทั้งหมดเก็บใน **เบราว์เซอร์ของคุณเท่านั้น** (localStorage)
- ไม่มีการส่งข้อมูลออกอินเทอร์เน็ต ยกเว้นการโหลดฟอนต์และ SheetJS
- ข้อมูลจะหายถ้า:
  - ล้าง Browser Cache / Data
  - ใช้โหมด Incognito
  - กดปุ่ม "ล้างข้อมูลทั้งหมด"
  - เปลี่ยนเบราว์เซอร์ / อุปกรณ์

💡 แนะนำให้ Export JSON เก็บไว้เป็นประจำ

## ❓ คำถามที่พบบ่อย (FAQ)

**Q: ทำไมเพิ่มพนักงานแล้วไม่เห็นในตาราง?**
A: ลองรีเฟรชหน้าเว็บ (F5) หรือตรวจสอบว่ากด "บันทึก" ในฟอร์มแล้ว

**Q: Assign ผลัดซ้ำในวันเดียวได้ไหม?**
A: ไม่ได้ — ระบบบังคับ 1 คน 1 ผลัด/วัน ถ้าเลือกใหม่จะแทนที่ของเดิม

**Q: ลบพนักงานแล้วตารางงานหายไหม?**
A: หาย — ระบบลบข้อมูล schedule ของพนักงานคนนั้นทั้งหมด (มี confirm ก่อนลบ)

**Q: Excel export แล้วภาษาไทยเป็นตัวต่างดาว?**
A: ระบบใส่ BOM (`\uFEFF`) ไว้แล้ว — ถ้ายังเพี้ยนให้ Import ผ่าน Google Sheets แทน

**Q: อยาก backup ข้อมูลย้ายไปเครื่องอื่น ทำยังไง?**
A: Export JSON → ส่งไฟล์ไป → Import JSON บนเครื่องปลายทาง

**Q: Reset แล้วกู้คืนได้ไหม?**
A: ไม่ได้ — ข้อมูลจะหายถาวร ควร Export ก่อน
